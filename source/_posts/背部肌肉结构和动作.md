# 背部肌肉的结构

背部肌肉主要分为浅层、中层、深层
具体可以参考知乎链接：https://zhuanlan.zhihu.com/p/30591313

我主要记录了浅层肌肉的结构和功能

| 分类       |          | 肌肉                                                                                     |
| ---------- | -------- | ---------------------------------------------------------------------------------------- |
| 背浅层肌   |          | 斜方肌、背阔肌、肩胛提肌、菱形肌 |
| 背中层肌   |          | 上后锯肌和下后锯肌<br>（这两者是呼吸肌，作用是助吸气，不详细介绍）|
| 背深层肌   | 背长肌   | 夹肌(包括头夹肌和颈夹肌)<br>竖脊肌(自外向内包括髂肋肌、最长肌、棘肌)<br>横突棘肌(由浅而深包括半棘肌、多裂肌和回旋肌) |
|            | 背短肌   | 连接各椎骨相邻突起之间的短小肌肉，主要有棘间肌、横突间肌和肋提肌等|

## 1. 斜方肌

肌肉可以参考![](/images/斜方肌3.png)

1. 部位：在颈部和背上部皮下，一侧形成三角形，两侧相合形成斜方形。
2. 起点：上项线内1/3, 枕外隆凸，项韧带，第7颈椎棘突，全部胸椎棘突及棘上韧带。
3. 止点：上部纤维止于锁骨外侧端1/3，中部纤维止于肩峰和肩胛冈上缘外侧，下部纤维止于肩胛冈上缘。
4. 功能
    - 近固定（脊柱固定）
      - 上部肌束收缩，使肩胛骨上提、上回旋、后缩(靠近脊住)。
      - 中部肌束收缩，使肩胛骨后缩。
      - 下部肌束收缩，使肩胛骨下降、上回旋、后缩。
      - 两侧同时收缩，使肩胛骨后缩。
    - 远固定(肩胛骨固定)
      - 一侧上部肌朿收缩，使头向同侧屈和向对侧旋转。
      - 两侧同时收缩，使头后仰和脊柱伸直(少儿时发展该肌可预防驼背)。
      - 此肌瘫痪时可发生塌肩。

## 2. 背阔肌

肌肉可以参考![](/images/背阔肌示意图.png)

1. 部位：在腰背部和胸部后外侧。
2. 起点：借腱膜起于第7-12胸椎及全部腰椎棘突，骶正中嵴，髂嵴后部和第10-12肋外面。
3. 止点：肱骨小结节嵴。
4. 机能：
    - 近固定：使上臂在肩关节处伸、内收和旋内。
    - 远固定：上肢上举后固定时，拉引躯干向上臂靠拢，提肋助吸气。(引体向上)

图片说明![](/images/背阔肌远近点固定说明.png)

## 3. 肩胛提肌

肌肉可以参考![](/images/肩胛提肌和菱形肌示意图.png)

1. 部位：在胸锁乳突肌和斜方肌深面。
2. 起点：第1-4颈椎横突。
3. 止点：肩胛骨上角和内侧缘上部。
4. 机能：
    - 近固定：**使肩胛骨上提和下回旋**。
    - 远固定：**一侧收缩，使头颈向同侧侧屈、后伸和下回旋。两侧收缩，使颈伸直**。

### 补充说明

肩胛提肌和斜方肌上部纤维协同作用可上提肩胛骨和使头后伸。

在另外一些场合，斜方肌使肩胛骨向上旋转时，肩胛提肌则拮抗斜方肌上部和下部纤维使肩胛骨向下旋转。

菱形肌协助肩胛提肌进行这种下旋，有助于在上肢的运动中保持关节盂的位置。关节盂的“操控”有利于增强肩关节的运动，尤其是内收时。

## 4. 菱形肌

肌肉可以参考![](/images/肩胛提肌和菱形肌示意图.png)

1. 部位：斜方肌深面。
2. 起点：第6-7颈椎和第1-4胸椎棘突 。
3. 止点：肩胛骨内侧缘下半部（肩胛冈以下）。
4. 机能：
    - 近固定：使肩胛骨上提、后缩和下回旋。
    - 远固定：两侧收缩，使脊柱颈、胸段伸直。
    - 此肌瘫痪时沿肩胛骨脊柱缘翘起呈翼状。

###　补充说明

- 在承重运动中，菱形肌和斜方肌、肩胛提肌及前锯肌协同作用将肩胛骨稳定于胸廓。

- 菱形肌和前锯肌虽然都附着于肩胛骨内侧缘，但它们的肌纤维走向却相反，因此，它们之间有着**特別明显的拮抗关系**，这两块有力肌的协同收缩有助于把肩胛骨牢牢稳定在胸廓背侧。

- 菱形肌如果发育不全（弱），会和前锯肌失去平衡，导致圆肩、肩胛骨前拉下降，颈椎出问题
- 反过来，如果菱形肌发育良好、肌力足够，就能维持肩胛骨的正常对位，让肩带肌肉保持平衡，有利于上半身健康。
