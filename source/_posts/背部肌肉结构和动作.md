# 背部肌肉的结构

背部肌肉主要分为浅层、中层、深层

### 背部及肩带相关肌肉分类表
| 一级分类       | 二级分类       | 三级分类       | 具体肌肉                                                                 | 核心功能简述                                                                 |
|----------------|----------------|----------------|--------------------------------------------------------------------------|------------------------------------------------------------------------------|
| **背部固有肌** | 背浅层肌| - | 斜方肌、背阔肌、肩胛提肌、菱形肌（大/小菱形肌）| 运动肩胛骨/肱骨、稳定上躯干，部分参与上肢运动 |
|                | 背中层肌 | - | 上后锯肌、下后锯肌 | 辅助呼吸（上后锯肌助吸气，下后锯肌助呼气），同时轻微稳定胸廓 |
|                | 背深层肌 | 背长肌 | 夹肌（头夹肌、颈夹肌）、竖脊肌（髂肋肌、最长肌、棘肌）、横突棘肌（半棘肌、多裂肌、回旋肌）| 脊柱的伸、侧屈、旋转运动，维持脊柱稳定性与直立姿势 |
|                |                | 背短肌 | 棘间肌、横突间肌、肋提肌 | 连接相邻椎骨/肋骨，精细调节脊柱姿势，维持脊柱节段稳定性 |
| **肩带肌（上肢带肌）** | 肩袖肌群（旋转袖） | - | 冈上肌、冈下肌、小圆肌、肩胛下肌 | 稳定盂肱关节，协同肩关节运动：冈上肌外展，冈下肌/小圆肌外旋，肩胛下肌内旋 |
|                | 非肩袖肩带肌   | - | 大圆肌、前锯肌、胸小肌、锁骨下肌 | 大圆肌辅助肩关节内收/内旋；前锯肌/胸小肌运动肩胛骨，辅助呼吸与上肢上举 |
| **其他背部相关肌（跨区）** | - | - | 胸大肌（胸背侧部分）、三角肌（后部纤维）| 胸大肌辅助肱骨内收/内旋；三角肌后部纤维辅助肩关节后伸/外旋，体表位于背部侧方 |

### 补充说明
1.  **肩带肌不算“背部固有肌”**
    解剖学上的“背部肌”，特指**起点或止点位于脊柱、肋骨、枕骨**，核心功能是运动脊柱的肌肉；而肩带肌的起点/止点集中在肩胛骨、肱骨，核心功能是肩关节/肩胛骨运动，因此被划分到「上肢肌」章节，只是体表位置在背部而已。

2.  **容易混淆的肌肉边界**
    - 菱形肌、肩胛提肌：虽然连接肩胛骨，但起点在脊柱，因此被归为背浅层肌。
    - 大圆肌：虽然位置和小圆肌相邻，但功能与背阔肌协同，也常被归为“背部辅助肌”，但解剖学归属仍为肩带肌。
    - 背阔肌：起点广泛覆盖下背部，但止点在肱骨，功能以肩关节运动为主，属于跨区的背浅层肌。

3.  **功能关联与协同**
    背部肌和肩带肌是高度协同的：比如做引体向上时，竖脊肌维持脊柱稳定，斜方肌/菱形肌内收肩胛骨，背阔肌/大圆肌内收肱骨，肩袖肌群稳定肩关节，多组肌肉共同完成动作。

## 1. 斜方肌

肌肉可以参考![](/images/斜方肌3.png)

1. 部位：在颈部和背上部皮下，一侧形成三角形，两侧相合形成斜方形。
2. 起点：上项线内1/3, 枕外隆凸，项韧带，第7颈椎棘突，全部胸椎棘突及棘上韧带。
3. 止点：上部纤维止于锁骨外侧端1/3，中部纤维止于肩峰和肩胛冈上缘外侧，下部纤维止于肩胛冈上缘。
4. 功能
    - 近固定（脊柱固定）
      - 上部肌束收缩，使肩胛骨上提、上回旋、后缩(靠近脊住)。
      - 中部肌束收缩，使肩胛骨后缩。
      - 下部肌束收缩，使肩胛骨下降、上回旋、后缩。
      - 两侧同时收缩，使肩胛骨后缩。
    - 远固定(肩胛骨固定)
      - 一侧上部肌朿收缩，使头向同侧屈和向对侧旋转。
      - 两侧同时收缩，使头后仰和脊柱伸直(少儿时发展该肌可预防驼背)。
      - 此肌瘫痪时可发生塌肩。

## 2. 背阔肌

肌肉可以参考![](/images/背阔肌示意图.png)

1. 部位：在腰背部和胸部后外侧。
2. 起点：借腱膜起于第7-12胸椎及全部腰椎棘突，骶正中嵴，髂嵴后部和第10-12肋外面。
3. 止点：肱骨小结节嵴。
4. 机能：
    - 近固定：使上臂在肩关节处伸、内收和旋内。
    - 远固定：上肢上举后固定时，拉引躯干向上臂靠拢，提肋助吸气。(引体向上)

图片说明![](/images/背阔肌远近点固定说明.png)

### 训练动作

> 功能：肩内收、肩后伸、内旋、伸躯干

1. 引体向上、高位下拉、直臂绳索下压 

## 3. 肩胛提肌

肌肉可以参考![](/images/肩胛提肌和菱形肌示意图.png)

1. 部位：在胸锁乳突肌和斜方肌深面。
2. 起点：第1-4颈椎横突。
3. 止点：肩胛骨上角和内侧缘上部。
4. 机能：
    - 近固定：**使肩胛骨上提和下回旋**。
    - 远固定：**一侧收缩，使头颈向同侧侧屈、后伸和下回旋。两侧收缩，使颈伸直**。

### 补充说明

肩胛提肌和斜方肌上部纤维协同作用可上提肩胛骨和使头后伸。

在另外一些场合，斜方肌使肩胛骨向上旋转时，肩胛提肌则拮抗斜方肌上部和下部纤维使肩胛骨向下旋转。

菱形肌协助肩胛提肌进行这种下旋，有助于在上肢的运动中保持关节盂的位置。关节盂的“操控”有利于增强肩关节的运动，尤其是内收时。

## 4. 菱形肌

肌肉可以参考![](/images/肩胛提肌和菱形肌示意图.png)

1. 部位：斜方肌深面。
2. 起点：第6-7颈椎和第1-4胸椎棘突 。
3. 止点：肩胛骨内侧缘下半部（肩胛冈以下）。
4. 机能：
    - 近固定：使肩胛骨上提、后缩和下回旋。
    - 远固定：两侧收缩，使脊柱颈、胸段伸直。
    - 此肌瘫痪时沿肩胛骨脊柱缘翘起呈翼状。

###　补充说明

- 在承重运动中，菱形肌和斜方肌、肩胛提肌及前锯肌协同作用将肩胛骨稳定于胸廓。

- 菱形肌和前锯肌虽然都附着于肩胛骨内侧缘，但它们的肌纤维走向却相反，因此，它们之间有着**特別明显的拮抗关系**，这两块有力肌的协同收缩有助于把肩胛骨牢牢稳定在胸廓背侧。

- 菱形肌如果发育不全（弱），会和前锯肌失去平衡，导致圆肩、肩胛骨前拉下降，颈椎出问题
- 反过来，如果菱形肌发育良好、肌力足够，就能维持肩胛骨的正常对位，让肩带肌肉保持平衡，有利于上半身健康。

## 5. 大圆肌

肌肉可以参考![](/images/大圆肌示意图.jpg)

1. 部位：位于人体肩部和背部的交界处，具体位置在肩胛骨的背侧，
2. 起点：肩胛骨下角外侧缘
3. 止点：肱骨前上方小结节嵴
4. 机能：
    - 肩内收：手臂从外展位置（远离身体中线，如侧平举的位置），向身体中线方向靠拢、回到体侧的动作。
    - 肩伸展：上臂于肩关节由前方向后方运动的动作。向后摆臂、游泳划水后半程均属于肩伸展；大圆肌可使肩关节后伸，与背阔肌、三角肌后束协同发力，完成后摆、划水及投掷类动作。
    - 肩内旋：上臂以肱骨长轴为中心，向内侧旋转的运动。典型动作如手背向后贴腰、系腰带等；大圆肌与肩胛下肌、胸大肌协同收缩，牵拉肱骨完成肩关节内旋，参与日常肢体活动及各类上肢发力动作。

###　补充说明

和背阔肌功能几乎一模一样，和背阔肌是兄弟关系，主要协助背阔肌工作。
