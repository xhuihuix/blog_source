# 修改权限指令

chmod指令主要用于修改**文件**和**目录**的权限.

## 方式1 基于组的权限设置

```bash
chmod g+r file
chmod g+w file
chmod o+r file
chmod go+r file
chmod g-r file
```

### 用户范围说明
- `u`: 文件所有者
- `g`: 文件所属组内用户
- `o`: 其他非本组用户
- `a`: 所有用户

### 权限操作符
- `+`: 表示在原有权限上增加
- `-`: 表示从原有权限中移除
- `=`: 表示强制赋值为指定权限

### 权限标识释义
- `r`：读取权限
- `w`：写入 / 修改权限
- `x`：执行权限（文件）/ 目录访问检索权限（文件夹）
- `X`：仅当目标为目录、或已有任意用户具备执行权限时，赋予执行权限
- `s`：执行时设置用户 ID (SUID) / 组 ID (SGID) 特殊权限
- `t`：限制删除标记（粘滞位，sticky bit）

## 方式2 基于数字的权限修改(绝对权限模式)

数字权限由1~4位八进制(0-7)组成, 其实主要由三位bit,权限数值分别对应4(100)/2(010)/1(001)表示, 共有4个八进制数,省略*高位*自动补零
- 第一位: 特殊权限位
    - 4: SUID权限
    - 2: SGID权限
    - 1: 粘滞位
- 第二位: 文件所有者权限(4读,2写,1执行)
- 第三位：所属组用户权限（数值规则同上）
- 第四位：其他用户权限（数值规则同上）

### 常见权限说明

1. 权限755
    - 7=4+2+1 -> 表示文件所有者有读/写/执行权限
    - 5=4+1   -> 表示所属组用户有写/执行权限
    - 5=4+1   -> 表示其他用户有写/执行权限
2. 权限 644
    - 6=4+2 -> 读 + 写
    - 4=4   -> 只读
    - 4=4   -> 只读

## 补充说明

1. 大写`X`(智能执行权限)规则
    - 目录:自动赋予进入/访问权限
    - 普通文件: 只有原本有执行权限,才会保留执行,否则不影响
    - 纯文本/配置文件这类原本无执行权限的,不会加`x权限

例如:

递归给整个文件夹批量改权限：
```bash
chmod -R a+X 文件夹名
```
- 所有子目录会获得访问权限
- 但普通日志\配置文件不会被错误加上执行权限

该指令本质上是针对`x`指令会对文件夹下所有文件和配置文件都加上`x`,可能存在被利用的安全隐患,才存在的`+X`配置
